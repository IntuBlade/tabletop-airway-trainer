# Trainer interface

## Practice and setup

Use iOS navigation, Dynamic Type and distinct titles for live blade practice, recorded practice and review. The photo introduces the training setting. The viewport shows the live blade image while acquiring the QR, then changes to the simulated airway. Recorded practice keeps a single large mark button under the view, with movement and position above it. Use amber for the learner’s marks and teal for reference overlays after reveal. Both use text labels so colour carries no decision alone.

The recorded exercise uses synthetic teaching fixtures and carries the same label on practice and review screens.
