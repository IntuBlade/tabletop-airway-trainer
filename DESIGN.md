# Trainer interface

## Practice and setup

Use iOS navigation, Dynamic Type and distinct titles for table placement, recorded practice and review. The photo introduces the training setting. The camera owns the screen during placement. Recorded practice keeps a single large mark button under the view, with movement and position above it. Use amber for the learner’s marks and teal for reference overlays after reveal. Both use text labels so colour carries no decision alone.

The placement model is a design stand-in. The recorded exercise uses synthetic teaching fixtures and carries the same label on practice and review screens.
